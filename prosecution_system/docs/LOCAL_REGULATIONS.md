# 地方性法规补充说明

## 当前状态

已集成 **775 部地方性法规**的元数据（标题、省份、日期、摘要）作为补充层。

- 数据源：`law_db` 数据库（law_research.db）
- 输出：`cases/legaldb/local_regulations_index.json`
- 覆盖：50 个省市自治区（上海市 65、北京市 52、江苏省 48、浙江省 48、重庆市 48 等）
- 已知数据质量问题：部分省份记录标注不准确（如"西藏人大常委会"实际收录北京法规）

## 数据局限

⚠️ **当前仅含摘要/概述（metadata），不含完整正文。**

| 数据 | 数量 | 完整度 |
|------|------|--------|
| 地方性法规（全部） | 12,040 部 | 含内容仅 6% |
| 已集成（有内容） | 775 部 | 平均 ~200 字 |

由于大部分地方性法规只有 200 字左右的元数据而无全文，**未纳入 RAG 检索索引**，避免低质量全文污染检索结果。

## 如何获取完整版

完整的地方性法规全文需从以下渠道专项采集：

1. **国家法律法规数据库** `https://flk.npc.gov.cn`（官方，需对应 API）
2. **各省人大/政府官网**（31 省市自治区）
3. **北大法宝** `https://www.pkulaw.com`（商业数据库）
4. **OpenLaw** `https://openlaw.cn`（部分免费）

采集重点优先级（与刑事追诉相关）：
- 各省《治安管理处罚条例实施细则》
- 各省《禁毒条例》
- 各省《道路交通安全条例》
- 各省《消防条例》
- 各省《看守所/监狱管理实施细则》

## 集成方式

`LegalDB` 已扩展以下方法：

```python
db = LegalDB()

# 按关键词搜索（匹配标题+摘要）
db.search_local_regulations(keyword='交通', top_k=5)

# 按省份列出
db.list_local_regulations_by_province('上海')

# 统计
db.stats()['local_regulations']  # 775
db.stats()['local_reg_by_province']  # 各省分布
```
