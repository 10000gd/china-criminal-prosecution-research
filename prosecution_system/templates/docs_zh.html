📁 案件管理

GET/api/cases

获取案件列表，支持分页和筛选

查询参数

page页码（默认1）
limit每页数量（默认20）
province省份筛选（可选）
crime_type罪名筛选（可选）
请求示例
curl -X GET "http://localhost:5000/api/cases?province=上海&crime_type=盗窃罪"

响应示例

{
  "cases": [
    {
      "case_id": "CASE-0001",
      "case_name": "上海市盗窃案",
      "crime_type": "盗窃罪",
      "amount": 89775.79,
      "province": "上海"
    }
  ],
  "total": 51,
  "page": 1
}

GET/api/case/{case_id}

获取案件详情

请求示例
curl -X GET "http://localhost:5000/api/case/CASE-0001"

响应字段

case_info: 案件基本信息 | charges: 罪名信息 | aggravating_factors: 从重情节 | mitigating_factors: 从轻情节 | legal_basis: 法律依据

200成功 404案件不存在

🔍 分析引擎

GET/api/case-analyze/{case_id}

案件综合分析，包含量刑预测、辩护建议、类案分析

请求示例
curl -X GET "http://localhost:5000/api/case-analyze/CASE-0001"

响应字段

case_info: 案件信息 | charges: 罪名 | defense: 辩护建议 | sentencing_prediction: 量刑预测 | similar_cases: 类案 | legal_basis: 法律依据

POST/api/case-analyze

新建案件分析（无需已有案件ID）

请求体

case_summary案件摘要对象
charges罪名列表
请求示例
curl -X POST "http://localhost:5000/api/case-analyze" \ -H "Content-Type: application/json" \ -d '{"case_summary":{"description":"盗窃1000元"},"charges":["盗窃罪"]}'

GET/api/fact-check/{case_id}

案件事实核查，返回每个字段的置信度等级

置信度等级

GRADE_A: ✅ 官方一手来源 | GRADE_B: 🔶 可推断来源 | GRADE_C: ⚠️ 需要验证 | GRADE_D: ❌ 无来源

⚖️ 入罪门槛

GET/api/threshold

查询各省盗窃罪、诈骗罪、抢夺罪等入罪门槛

查询参数

crime罪名（盗窃罪/诈骗罪/抢夺罪）
province省份（默认全国标准）
请求示例
curl -X GET "http://localhost:5000/api/threshold?crime=盗窃罪&province=北京"

响应示例

{
  "crime": "盗窃罪",
  "province": "北京",
  "amount_large": 2000,
  "amount_massive": 50000,
  "amount_especially_massive": 400000,
  "reached": true,
  "legal_basis": "最高法最高检《关于办理盗窃刑事案件适用法律若干问题的解释》"
}

📖 法律检索

GET/api/law/search

基于 RAG 的法律全文智能检索（2055部法律法规）

查询参数

q检索关键词
category分类筛选（法律/司法解释/行政法规）
limit结果数量（默认10）
请求示例
curl -X GET "http://localhost:5000/api/law/search?q=正当防卫&limit=5"

响应字段

results: 检索结果列表 | score: 相似度分数 | article: 条款 | law: 法律名称 | preview: 内容预览

🛡️ 辩护增强

POST/api/defense/analyze

案件辩护分析，识别辩护角度和策略

请求体

case_id案件ID

响应字段

primary_defense: 主要辩护意见 | secondary_defenses: 辅助辩护意见 | recommended_strategy: 推荐策略 | overall_strength: 综合强度(0-100)

POST/api/defense/opinion

生成辩护词文档

请求示例
curl -X POST "http://localhost:5000/api/defense/opinion" \ -H "Content-Type: application/json" \ -d '{"case_id":"CASE-0001"}'

响应字段

opinion: 辩护词内容 | defendant: 被告人 | charge: 罪名 | key_defenses: 核心辩护点

GET/api/defense/search

辩护案例库检索

请求示例
curl -X GET "http://localhost:5000/api/defense/search?q=自首&crime=盗窃罪"

GET/api/stats/provincial-diffs

各省入罪门槛差异对比

GET/api/stats/company-geo

企业犯罪地理分布热力图数据

GET/api/stats/hallucination

数据幻觉率统计（C-CLAIM溯源评估）
