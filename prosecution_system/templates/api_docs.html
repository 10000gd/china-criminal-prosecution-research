⚖️ API 文档

刑事追诉智能辅助系统 v2.0 · OpenAPI 3.0

📋 认证接口
GET /auth/login 认证
登录页面 / 接口（支持 JSON 和表单）
请求参数
usernamestring必填用户名
passwordstring必填密码
⚖️ 案件管理
GET /api/cases 案件
获取案件列表
响应
{
  "cases": [...],
  "total": 50,
  "page": 1
}
GET /api/case/{case_id} 案件
获取案件详情
路径参数
case_idstring必填案件编号，如 CASE-0001
🔍 法律检索
GET /api/law/search?q={query} 法律
全文法律检索（BM25 + TF-IDF）
查询参数
qstring必填检索关键词，如"正当防卫"
limitinteger返回数量，默认10
⚖️ 入罪门槛
GET /api/threshold?crime={crime}&province={province}&amount={amount} 门槛
查询罪名入罪门槛（支持11个罪名，33-36省）
查询参数
crimestring必填罪名：盗窃罪/诈骗罪/抢夺罪/敲诈勒索罪/职务侵占罪/故意伤害罪/交通肇事罪/非法吸收公众存款罪/集资诈骗罪/开设赌场罪/毒品犯罪
provincestring省份，如"广东"（可选，不填返回全国）
amountnumber金额（元），用于判断是否达到入罪门槛
响应示例
{
  "crime": "盗窃罪",
  "province": "广东",
  "threshold_yuan": 3000,
  "threshold_wan": 0.3,
  "reached": true,
  "legal_basis": "最高法最高检《关于办理盗窃刑事案件...》(2013)"
}
