📖 基础信息

认证方式

大部分API需要登录认证。使用以下方式：

# 登录获取session curl -X POST http://localhost:5000/auth/login \ -H "Content-Type: application/json" \ -d '{"username": "your_user", "password": "your_pass"}' \ -c cookies.txt # 使用session访问受保护API curl http://localhost:5000/api/cases -b cookies.txt

响应格式

所有API返回JSON格式。成功响应：

{ "success": true, "data": { ... } }

错误响应：

{ "error": "错误信息", "code": "error_code" }

🔐 认证 API

POST /auth/login

用户登录

请求体: {"username": "string", "password": "string"}
curl -X POST http://localhost:5000/auth/login \ -H "Content-Type: application/json" \ -d '{"username": "admin", "password": "123456"}'
POST /auth/register

用户注册

请求体: {"username": "string", "email": "string", "password": "string", "role": "user|lawyer|prosecutor"}
GET /auth/logout

退出登录

GET /auth/profile

获取用户资料（需登录）

📁 案件 API

GET /api/cases

获取案件列表

参数: status (可选): investigating|prosecuted|judged|appealed|closed
curl http://localhost:5000/api/cases?status=judged
GET /api/case/<case_id>

获取案件详情

curl http://localhost:5000/api/case/CASE-001

🛡️ 辩护 API

GET /api/defense/search

搜索辩护案例

参数: crime - 罪名
defense_type - 辩护类型
limit - 返回数量（默认10）
curl "http://localhost:5000/api/defense/search?crime=盗窃罪&defense_type=正当防卫"
POST /api/defense/analyze

分析案件辩护角度

请求体: {"case_id": "string", "crime": "string", "facts": "string"}
POST /api/defense/opinion

生成辩护意见

请求体: {"case_id": "string", "defense_type": "string", "facts": "string"}

⚖️ 量刑 API

GET /api/sentencing/report

获取量刑一致性报告

参数: crime (可选) - 按罪名筛选
curl "http://localhost:5000/api/sentencing/report?crime=盗窃罪"
POST /api/sentencing/deviation

分析个案量刑偏离度

请求体: {"case_id": "string", "crime": "string", "sentence_years": number, "province": "string", "is_自首": bool, ...}
curl -X POST http://localhost:5000/api/sentencing/deviation \ -H "Content-Type: application/json" \ -d '{"crime": "盗窃罪", "sentence_years": 2.0, "province": "北京", "is_自首": true}'
GET /api/sentencing/provincial

获取各省量刑对比

📊 对比 API

POST /api/compare

对比多个案件

请求体: {"case_ids": ["CASE-001", "CASE-002", ...]}
curl -X POST http://localhost:5000/api/compare \ -H "Content-Type: application/json" \ -d '{"case_ids": ["CASE-001", "CASE-002"]}'

📥 导出 API

GET /export/case/<case_id>

导出案件报告（HTML格式，可打印为PDF）

GET /export/comparison

导出对比报告

参数: case_id - 案件ID（可多个）
curl "http://localhost:5000/export/comparison?case_id=CASE-001&case_id=CASE-002" -o report.html

⭐ 收藏 API

GET /auth/favorites

获取收藏列表（需登录）

POST /auth/favorites

添加收藏

请求体: {"case_id": "string"}
DELETE /auth/favorites

移除收藏

请求体: {"case_id": "string"}

💡 使用示例

Python 示例

import requests # 登录 session = requests.Session() session.post("http://localhost:5000/auth/login", json={"username": "admin", "password": "123456"}) # 获取量刑报告 report = session.get("http://localhost:5000/api/sentencing/report") print(report.json()) # 分析偏离度 result = session.post("http://localhost:5000/api/sentencing/deviation", json={"crime": "盗窃罪", "sentence_years": 2.0}) print(result.json())

JavaScript 示例

// 登录 const loginRes = await fetch('/auth/login', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({username: 'admin', password: '123456'}), credentials: 'include' }); // 获取量刑报告 const report = await fetch('/api/sentencing/report', {credentials: 'include'}); const data = await report.json();
