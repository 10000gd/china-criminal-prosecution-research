# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Currently active |

## Reporting a Vulnerability

If you discover a security issue, please report it via:
- GitHub Issues (for non-sensitive issues)
- Or contact the repository owner directly

Please **do not** report security vulnerabilities through public channels.

## Security Practices

- All legal references are verified against primary sources
- Zero hallucination citation standard maintained
- Evidence chains are reproducible and traceable
- No sensitive personal data is stored in this repository
- GitHub Secret Scanning is enabled on this repository

## Dependencies

This project uses the following dependencies. Please keep them updated:

- Python 3.8+
- LaTeX (xeLaTeX)
- GitHub Actions (automated build pipeline)

No known security vulnerabilities in current dependencies.
