## Overview

This project provides a comprehensive, systematic analysis of criminal prosecution feasibility in China's legal system. It combines:

- **Legal theory** — deep analysis of criminal procedure law and evidence standards
- **Case studies** — real-world application (including major financial crime cases)
- **Automated tools** — Python + LaTeX pipeline for generating professional reports
- **Evidence chain methodology** — a complete, reproducible framework for building prosecution cases

**Quality standard: 0 hallucination citations.** Every legal reference, case citation, and data point is traceable and verifiable.

## Quick Start

### Build Report

```bash
# Clone
git clone https://github.com/10000gd/china-criminal-prosecution-research.git
cd china-criminal-prosecution-research/hengda_final_report

# Build
python build_report.py
```

### Requirements

- Python 3.8+
- LaTeX (xeLaTeX with xeCJK for Chinese support)

### Output

Generates `hengda_full_report.pdf` — a professionally formatted, publication-ready legal research report.
